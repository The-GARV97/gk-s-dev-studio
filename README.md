# GK's Dev Studio

Create a complete personal portfolio web application for Gaurav Khetwal, a full-stack developer.

The experience should feel like a polished native application rather than a traditional scrolling portfolio website. Use a modern Neumorphism design language throughout the interface. Let the visual system, colors, typography, spacing, and decorative details be decided creatively.

Core experience:

- Build the portfolio as a responsive React web application.

- Use Tailwind CSS for styling and responsive behavior.

- Use Framer Motion for smooth, premium animations and transitions.

- Support desktop, tablet, and mobile devices.

- Make the experience accessible and keyboard-friendly.

- Respect prefers-reduced-motion.

- Keep animations elegant, smooth, and purposeful.

Navigation:

- Create a persistent floating bottom navigation dock inspired by an iOS app dock.

- The dock must remain at the bottom on desktop and mobile.

- Include Home, About, Work, Skills, and Contact.

- Clearly indicate the active section.

- Add smooth animated transitions between sections.

- Make the portfolio behave like a single-page application, with each section feeling like a separate app screen.

- Support direct URLs or hash-based navigation for every section.

Home screen:

- Introduce “Gaurav Khetwal” as a full-stack developer.

- Use a strong headline about turning complex problems into clear, useful software.

- Include primary actions for viewing work and starting a conversation.

- Add an original developer-focused hero visual or interactive composition.

- Include subtle floating developer-related elements, status indicators, or code-inspired details.

- Do not use a generic stock-photo layout.

About screen:

- Present Gaurav as a developer, product thinker, and problem solver.

- Explain a working process based on understanding, designing, building, validating, and improving.

- Use interactive neumorphic cards.

- Keep the copy concise and confident.

Work screen:

- Create a premium project gallery with interactive case-study cards.

- Each project should support:

  - Project title

  - Short description

  - Role

  - Technology stack

  - Challenge

  - Solution

  - Outcome

  - Screenshots

  - Live demo link

  - Source-code link

- Open projects in an animated modal, drawer, or dedicated detail view.

- Use clearly marked placeholder content instead of inventing clients, statistics, or professional achievements.

Skills screen:

- Organize capabilities into Frontend, Backend, Databases, Tools, Product Thinking, and Deployment.

- Present skills through polished interactive components instead of ordinary progress bars.

- Include a developer terminal-inspired component that fits naturally within the neumorphic application theme.

Contact screen:

- Create a functional contact form with:

  - Name

  - Email

  - Subject

  - Message

- Add client-side and server-side validation.

- Save every valid submission to a database.

- Show clear animated loading, success, and error states.

- Prevent duplicate submissions and add basic spam/rate-limit protection.

- Include editable placeholders for email, GitHub, LinkedIn, location, and other social profiles.

Additional functionality:

- Add a theme switcher with saved user preference.

- Add smooth page entrances, staggered card reveals, hover feedback, button press effects, modal transitions, and animated navigation indicators.

- Use animations that reinforce the app-like feeling without becoming distracting.

- Add a short, refined loading experience.

- Make all content easy to edit from centralized data objects or configuration files.

- Use reusable, production-quality components.

- Do not include fake testimonials, employers, clients, experience duration, project outcomes, or personal statistics.

- Ensure the final result feels distinctive, professional, technically credible, and clearly made for a full-stack developer.
